# Simulación de Nave Espacial 2D (Pygame)

Proyecto de simulación interactiva desarrollado en Python con Pygame para la materia de **Graficación**.

## 🚀 Requisitos previos
* Tener instalado **Python** en la computadora.

## ⚙️ Cómo ejecutar el proyecto localmente:

1. Abrir terminal o línea de comandos en la carpeta del proyecto.
2. Instalar la librería Pygame ejecutando el siguiente comando:
   ```bash
   pip install pygame

python game.py
